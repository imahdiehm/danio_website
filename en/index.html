06 / GOOD QUESTIONS

A closer look.

What is agent-based modeling?

An approach that represents individuals as agents with local rules. Their interactions with the environment and one another produce collective patterns that can be studied.

Is this playground the actual plugin?

No. This browser illustration uses a small grid and simplified routing to explain the idea. The native C# plugin has its own simulation policy, recording, metrics, and validation routes.

How do I get started?

The technical guide describes building the single Surica.gha file and loading it into Grasshopper. You need Windows, the .NET SDK, and the installed Rhino SDK to build the current plugin. No public binary download is provided here.

Does Danio use AI or live digital-twin data?

The current native workflow uses rule-based agents and recorded simulation results. The animated floor plan is a concept illustration; no machine-learning inference, sensor connection, or live physical synchronization is included.

Can the model validate evacuation safety?

The project supports research and scenario exploration. Physical calibration and independent behavioral validation are required before using results for safety decisions.
